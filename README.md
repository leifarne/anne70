# anne70

This repository is configured to publish to GitHub Pages.

## How publishing works

- The workflow at `.github/workflows/deploy-pages.yml` deploys on every push to `main`.
- The site content is served from `index.html`.
- After enabling **Settings → Pages → Build and deployment → Source: GitHub Actions**, the site will be available at:
  - `https://leifarne.github.io/anne70/`
